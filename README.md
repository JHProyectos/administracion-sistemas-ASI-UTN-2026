# Administración de Sistemas de Información — UTN FRVT 2026

Material de estudio de la materia **Administración de Sistemas de Información (ASI)** de la UTN Facultad Regional Venado Tuerto, ciclo 2026.

Las presentaciones y apuntes de cátedra de las **Unidades 1 a 4**, originalmente en PDF, están convertidos a **Markdown** para que sean más fáciles de leer, buscar, citar y reutilizar (por ejemplo, como fuente para resumir o para trabajar con herramientas de IA).

Las **Unidades 5 y 6** tienen un resumen de estudio propio, uno por unidad, y en `material/` están los PDF de teoría y los trabajos prácticos ordenados por unidad.

## Cómo leerlos

**En GitHub:** hacé clic en cualquiera de los `.md` de la tabla y se muestran formateados.

**En MD Reader (recomendado):** para una lectura más cómoda y para **exportar a PDF**, usá
 **[Lector MD](https://mdreader.jhproyectos.com.ar/)**

1. Descargá el `.md` que quieras leer (o cloná el repo).
2. Abrilo en [mdreader.jhproyectos.com.ar](https://mdreader.jhproyectos.com.ar/).
3. Leelo con el formato ya aplicado y, si lo necesitás impreso o para compartir, exportalo a PDF desde la misma página.

git clone https://github.com/JHProyectos/administracion-sistemas-ASI-UTN-2026.git
